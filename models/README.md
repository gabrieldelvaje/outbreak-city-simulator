# models

Pasta reservada para os modelos 3D personalizados do projeto.

Formato preferencial: `.glb`.

Cada landmark deverá ter, além do arquivo 3D, metadados de:
- longitude;
- latitude;
- altitude;
- rotação;
- escala;
- fonte/modelagem;
- licença.

A V1 usa apenas extrusões automáticas dos footprints de edifícios.
